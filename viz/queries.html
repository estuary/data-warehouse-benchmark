How did each engine do on each query?

The benchmark ran 244 queries from three public suites. TPC-DS has 99 join queries over evenly distributed data. DSB runs 102 queries over the same tables with skewed data, numbered to match TPC-DS so that each shared number is a pair. ClickBench has 43 scan queries over one wide table of page views.

Each time below is the median server-side time of three measured runs with one user, on each engine's designated size for that data volume. ClickBench times are at each engine's entry tier on the fixed table. Choose a suite and a data volume, narrow the list by query pattern or by number, and click any column heading to sort. Click a query to see it on every engine, at every data volume and compute size, in the card at the bottom of the page, which ends with links to the SQL each engine ran.
